#JavaScript Solo Project

Rock Paper Scissors • Pig Latin Translator • Caesar Cipher
Live Demo: https://gmlane1985.github.io/JavaScript-Solo-Project/
This repository contains my solo JavaScript project, built as part of the Node.js command‑line module. The project includes three interactive programs implemented in JavaScript and presented through a browser‑based interface.
The goal of the project was to step outside the browser environment, build small programs that run in the terminal using Node.js, and demonstrate understanding of JavaScript fundamentals such as string manipulation, randomization, argument parsing, and modular program structure.
A live HTML version is provided for easy demonstration and testing.

---

##📌 Project Overview
This project includes three separate JavaScript tools:
🎮 Rock Paper Scissors
A simple game where the player chooses rock, paper, or scissors, and the computer randomly selects its own move. The program determines the winner and displays the result.
🐷 Pig Latin Translator
A text converter that transforms English phrases into Pig Latin using standard rules for vowels and consonant clusters.
🔐 Caesar Cipher Encryption
An encryption tool that shifts each letter of a phrase left or right in the alphabet based on a positive or negative shift value. Case‑insensitive and preserves non‑letter characters.
All three tools are implemented in JavaScript and showcased through the live HTML interface.
