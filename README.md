# JavaScript Solo Project

## Rock Paper Scissors • Pig Latin Translator • Caesar Cipher

---

### 📌 Project Overview

This project contains three interactive JavaScript programs implemented as part of a solo assignment, all three programs are also available through a browser‑based HTML interface.

---

### 🎮 Rock Paper Scissors

A simple game where the player selects rock, paper, or scissors, and the computer randomly generates its own move. The program determines the winner and displays the result.

---

### 🐷 Pig Latin Translator

A text converter that transforms English phrases into Pig Latin using standard rules for vowels and consonant clusters.

---

### 🔐 Caesar Cipher Encryption

An encryption tool that shifts each letter of a phrase left or right in the alphabet based on a positive or negative shift value.
Case‑insensitive and preserves non‑letter characters.

---
