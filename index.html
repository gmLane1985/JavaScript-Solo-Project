JavaScript Solo Project - Garrett Lane

In this solo project we were tasked with creating three 'programs'.

  • A rock paper scissors game that:
    1. randomly generates computer moves
    2. determines the winner
    3. outputs the result
  • A pig latin program that:
    1. converts each word according to Pig Latin rules
    2. outputs the translated text
  • A Caesar decipher program that:
    1. takes a phrase and a shift number
    2. applies the shift (both positive and negative)
    3. outputs the encrypted text
